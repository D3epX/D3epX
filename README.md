## Selected work

### [Arabic NLP Research Platform — SANAD](https://github.com/itsbtb18/Plateforme_NLP)
Contributed AI and backend systems to a multilingual research platform at the Algerian Academy of the Arabic Language. Work included conversational RAG, document processing, platform and web search, and automated collection of Arabic NLP resources from more than 198 sources.

**Django · FastAPI · Qdrant · Elasticsearch · Celery**

### [Agentic Legal RAG](https://github.com/D3epX/Agentic-Legal-RAG-DZ)
A multilingual legal question-answering assistant combining document retrieval, web search fallback, and faithfulness verification. Uses BGE-M3, BM25, Qdrant, reciprocal rank fusion, and reranking.

> Evaluation experiments: **Precision@5 0.75 · Recall@5 0.94 · MRR 0.88 · BERTScore F1 0.95**.

### [Knowledge Extraction Pipeline](https://github.com/D3epX/Knowladge-extraction-pipline-)
An educational document intelligence and RAG pipeline using **Docling**, **LanceDB**, and **Streamlit** to parse, chunk, index, search, and chat with documents.

### [CarRacing PPO](https://github.com/D3epX/max-verstappen)
A deep reinforcement learning project training continuous-control racing agents on Gymnasium's CarRacing environment. Uses PPO with CNN-based visual encoders, PyTorch, and Stable-Baselines3.

### [Code Rank](https://github.com/D3epX/code-Rank)
A gamified practice tracker combining time tracking, GitHub activity, streaks, and a rank-based leaderboard. Built with Next.js, TypeScript, FastAPI, PostgreSQL, and Redis.
